# StayRelive

StayRelive is a modern, user-friendly apartment booking platform designed to help travelers find comfortable stays and homeowners manage their rental listings with ease.
This project includes features like apartment search and bookings, host dashboards, and a clean, responsive UI.

| Layer               | Technologies                                                |
| ------------------- | ----------------------------------------------------------- |
| **Frontend**        | HTML, CSS, JAVASCRIPT |
| **Backend**         | DRUPAL |
| **Database**        | MySQL |
| **Deployment**      | GITHUB |
| **Maps & Location** | Google Maps API |
